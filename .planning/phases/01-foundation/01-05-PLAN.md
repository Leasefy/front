<task type="auto">
  <name>Task 1: Create Vercel configuration</name>
  <files>vercel.json, .vercelignore</files>
  <action>
    Create vercel.json with optimal configuration:

    ```json
    {
      "$schema": "https://openapi.vercel.sh/vercel.json",
      "framework": "nextjs",
      "regions": ["iad1"],
      "headers": [
        {
          "source": "/(.*)",
          "headers": [
            {
              "key": "X-Content-Type-Options",
              "value": "nosniff"
            },
            {
              "key": "X-Frame-Options",
              "value": "DENY"
            }
          ]
        }
      ]
    }
    ```

    Region "iad1" (US East) is closest to Neon's default region and serves Colombia well.

    Create .vercelignore:
    ```
    .git
    .env.local
    .env*.local
    node_modules
    prisma/seed.ts
    src/lib/seed-data.ts
    ```

    Note: Prisma schema IS deployed (needed for migrations), but seed scripts are not.
  </action>
  <verify>vercel.json is valid JSON, .vercelignore exists</verify>
  <done>Vercel configuration ready with security headers and optimal region</done>
</task>

<task type="auto">
  <name>Task 2: Deploy to Vercel via CLI</name>
  <files>N/A (deployment)</files>
  <action>
    Ensure Vercel CLI is available:
    ```bash
    npx vercel --version || npm install -g vercel
    ```

    Deploy to Vercel:
    ```bash
    npx vercel --yes
    ```

    This will:
    1. Link to Vercel account (may require login)
    2. Create project if not exists
    3. Deploy preview

    Capture the deployment URL from output.

    Set environment variables:
    ```bash
    npx vercel env add DATABASE_URL production
    # Enter the Neon connection string when prompted
    ```

    Deploy to production:
    ```bash
    npx vercel --prod
    ```
  </action>
  <verify>vercel ls shows deployment, curl {preview-url} returns 200</verify>
  <done>Application deployed to Vercel preview and production</done>
</task>
