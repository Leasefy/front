# Plan 03-01: ConsignacionCard + Lista Consignaciones

## Objective
Create the Portafolio (consigned properties list) page with ConsignacionCard, ConsignacionTable, and filtering capabilities. This is the main view for managing all properties consigned to the agency.

## Execution Context
- **Module**: Inmobiliaria Dashboard
- **Route**: `/panel/inmobiliaria/portafolio`
- **Patterns**: Follow PropietarioCard/PropietarioTable patterns from Phase 2
- **Data**: Use MOCK_CONSIGNACIONES from mock-inmobiliaria.ts
- **Types**: Consignacion, ConsignacionStatus, PropertyAvailability from inmobiliaria.ts

## Context References
- `src/components/inmobiliaria/PropietarioCard.tsx` - Card pattern reference
- `src/components/inmobiliaria/PropietarioTable.tsx` - Table pattern reference
- `src/lib/types/inmobiliaria.ts:110-173` - Consignacion types
- `src/lib/data/mock-inmobiliaria.ts:521+` - MOCK_CONSIGNACIONES data
- `docs/ROADMAP-INMOBILIARIA.md:237-241` - Phase 3 requirements

</task>
