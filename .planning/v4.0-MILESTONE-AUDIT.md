### Critical Issues Found & Fixed

| Priority | Issue | Fix |
|----------|-------|-----|
| P0 | `/panel/beta/layout.tsx` missing `I18nProvider` — route outside `(landlord)` group, all Beta components call `useI18n()` which throws without provider | Added `I18nProvider` wrapper |
| P0 | `/panel/beta/layout.tsx` missing `ProtectedRoute` — unauthenticated access to Beta AI interface | Added `<ProtectedRoute allowedRoles={['landlord']}>` |
| P2 | `switchConversation` in useBetaChat didn't trigger tab change — clicking DecisionHistory entry stayed on Decisiones tab | Added `onTabChangeRef.current?.('conversations')` |

**Fix commit:** `8bc10ac fix(audit): add I18nProvider + ProtectedRoute to propietarios beta route, fix DecisionHistory tab switch`

Note: `/panel/inmobiliaria/beta/layout.tsx` does NOT need these fixes because it's nested inside `/panel/inmobiliaria/layout.tsx` which already provides both `ProtectedRoute` and `I18nProvider`.
