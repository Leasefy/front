  <name>Task 1: Create gap-filling engine</name>
  <files>src/components/inmobiliaria/import/lib/gapFiller.ts</files>
  <action>
    Create the mock AI gap-filling engine. This is deterministic heuristic logic that simulates AI behavior.

    **`analyzeProperties(properties: ImportProperty[]): ImportProperty[]`**

    For each property, detect missing/invalid fields and generate AISuggestion entries:

    **Rule 1: Missing monthlyRent**
    - If monthlyRent is missing, zero, or NaN
    - Suggest based on city + propertyType from RENT_ESTIMATES table
    - Confidence: 'media'
    - Reasoning: "Estimado basado en promedios de mercado para {{type}} en {{city}}"

    **Rule 2: Missing propertyZone**
    - If propertyZone is empty
    - Suggest "Por definir"
    - Try to extract from propertyAddress (look for known barrio names)
    - Confidence: 'baja'
    - Reasoning: "No se detectó barrio. Revisa manualmente."

    **Rule 3: Missing propertyType or ambiguous**
    - If propertyType doesn't match the enum values
    - Normalize Spanish variants: 'apto' | 'apartamento' → 'apartment', 'casa' → 'house', 'local' | 'comercial' → 'commercial', 'oficina' → 'office', 'bodega' → 'warehouse', 'estudio' → 'studio'
    - If normalization succeeds, auto-apply (not a suggestion, direct fix) with note
    - If cannot normalize, suggest 'apartment' as default
    - Confidence: 'media'
    - Reasoning: "Tipo normalizado de '{{original}}' a '{{normalized}}'"

    **Rule 4: Missing propertyCity**
    - Extract from propertyAddress if possible (check against COLOMBIAN_CITIES list)
    - COLOMBIAN_CITIES: ['Bogotá', 'Medellín', 'Cali', 'Barranquilla', 'Cartagena', 'Bucaramanga', 'Pereira', 'Manizales', 'Santa Marta', 'Ibagué', 'Villavicencio', 'Armenia', 'Neiva', 'Popayán', 'Montería', 'Pasto']
    - Confidence: 'media' if found in address, 'baja' if not
    - Reasoning: "Ciudad detectada en la dirección" or "No se pudo detectar ciudad"

    **Rule 5: Missing commissionPercent**
    - Suggest 10 (Colombian market default)
    - Confidence: 'alta'
    - Reasoning: "Porcentaje estándar del mercado colombiano (8-12%)"

    **Rule 6: Missing propertyTitle**
    - Generate from available data: `${propertyType} en ${propertyZone || propertyCity}`
    - Confidence: 'media'
    - Reasoning: "Título generado automáticamente"

    **RENT_ESTIMATES table:**
    ```typescript
    export const RENT_ESTIMATES: Record<string, Record<string, number>> = {
      'bogota':       { apartment: 1800000, house: 2800000, studio: 1200000, commercial: 3500000, office: 2500000, warehouse: 4000000 },
      'medellin':     { apartment: 1600000, house: 2400000, studio: 1000000, commercial: 3000000, office: 2200000, warehouse: 3500000 },
      'cali':         { apartment: 1400000, house: 2000000, studio: 900000, commercial: 2500000, office: 1800000, warehouse: 3000000 },
      'barranquilla': { apartment: 1300000, house: 1800000, studio: 800000, commercial: 2200000, office: 1600000, warehouse: 2800000 },
      'default':      { apartment: 1500000, house: 2200000, studio: 950000, commercial: 2800000, office: 2000000, warehouse: 3200000 },
    };
    ```

    **Error detection:** After suggestions, check if property still has unresolvable issues:
    - No propertyAddress at all → `hasErrors: true`, errorMessage: "Dirección requerida"
    - No monthlyRent and no suggestion possible → `hasErrors: true`
    - Set `selected: true` for properties without errors, `selected: false` for those with errors

    **`cleanNumericValue(value: unknown): number | undefined`** helper
    - Strips `$`, `.`, `,`, spaces from string values
    - Handles both `1.800.000` (Colombian format) and `1,800,000` (US format)
    - Returns parsed number or undefined
  </action>

    const handleImport = async () => {
      setIsImporting(true);
      const selectedProps = state.properties.filter(p => p.selected && !p.hasErrors);
      const total = selectedProps.length;
      
      // Simulate import with progress
      for (let i = 0; i <= total; i++) {
        await new Promise(r => setTimeout(r, Math.max(50, 2000 / total)));
        setProgress(Math.round((i / total) * 100));
      }
      
      console.log('Imported properties:', selectedProps);
      updateState({ importedCount: total, importProgress: 100 });
      setIsImporting(false);
      setIsComplete(true);

        title: t('inmobiliaria.import.confirm.toast.successTitle'),
        description: t('inmobiliaria.import.confirm.toast.successDesc', { count: total }),
