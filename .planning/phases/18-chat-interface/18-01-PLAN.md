# Plan 18-01: Chat State Management + Message Bubble Components

## Goal
Build the core chat infrastructure: types, state hook, message bubbles, and chat input. After this plan, users can type messages and see mock AI responses appear as styled bubbles.

## Context

Phase 17 built the Mission Control layout with BetaLayout (fixed inset-0 z-50), BetaSidebar (260px, 4 tabs), and BetaWelcome (suggested prompts with onPromptClick callback). The content area currently renders `{children}` which is BetaWelcome.

This plan replaces BetaWelcome with a functional chat experience once messages exist.

### Integration Points
- `BetaLayout.tsx` renders `<main className="flex-1 overflow-y-auto">{children}</main>`
- `BetaWelcome` has `onPromptClick?: (prompt: string) => void`
- `page.tsx` currently renders `<BetaWelcome />`
- Beta uses indigo color palette, dark mode support, Phosphor icons

### Key Decisions
- **No external chat SDK**: Build `useBetaChat` hook with local useState — mock responses now, swappable to real API in Phase 24
- **Mock responses**: Hardcoded response map keyed by keywords. Simulates 1-2s delay before response appears.
- **Message model**: `{ id, role, content, timestamp, status }` — status tracks 'sending'|'sent'|'streaming'|'complete'|'error'
- **Streaming simulation**: Use character-by-character reveal (adapted from existing useTypingAnimation pattern in score/useTypingAnimation.ts)
- **No markdown yet**: Plain text rendering in bubbles. Markdown support added in 18-02.

## Tasks

### Task 1: Chat types + useBetaChat hook + mock response engine

**Files to create:**
- `src/lib/types/beta-chat.ts` — Message type, Conversation type, ChatState type
- `src/lib/hooks/useBetaChat.ts` — Core chat state hook with mock response simulation
- `src/lib/data/mock-chat-responses.ts` — Keyword-based mock AI responses

**Chat types (`beta-chat.ts`):**
```typescript
export type MessageRole = 'user' | 'assistant' | 'system';
export type MessageStatus = 'sending' | 'sent' | 'streaming' | 'complete' | 'error';

export interface ChatMessage {
  id: string;
  role: MessageRole;
  content: string;
  timestamp: Date;
  status: MessageStatus;
}

export interface Conversation {
  id: string;
  title: string;
  messages: ChatMessage[];
  createdAt: Date;
  updatedAt: Date;
}
```

**useBetaChat hook (`useBetaChat.ts`):**
- `messages: ChatMessage[]` — current conversation messages
- `sendMessage(text: string): void` — adds user message, triggers mock response
- `isStreaming: boolean` — true while assistant message is being "streamed"
- `streamingContent: string` — partial content during streaming
- Mock engine: on sendMessage, wait 800-1500ms, then start character-by-character reveal of mock response at ~40 chars/sec
- Uses `useCallback` and `useRef` for timeout management (same pattern as useTypingAnimation)
- Generates unique IDs with `crypto.randomUUID()` or Date.now fallback

**Mock responses (`mock-chat-responses.ts`):**
- Map of keyword patterns to realistic Spanish responses about Colombian rental management
- Keywords: cobros, propiedades, decisiones, reporte, mantenimiento, contrato, inquilino, mora, pago
- Fallback response for unrecognized inputs
- Each response 2-4 sentences, realistic landlord assistant tone
- Export `getMockResponse(userMessage: string): string`

**Must-haves for Task 1:**
1. ChatMessage interface exported from beta-chat.ts with all fields
2. useBetaChat returns { messages, sendMessage, isStreaming }
3. sendMessage adds user message immediately, triggers mock assistant response after delay
4. Mock response text reveals character by character (streaming simulation)
5. At least 8 keyword-matched mock responses in Spanish

**Commit:** `feat(18): chat types, useBetaChat hook, and mock response engine`

### Task 2: Message bubbles + ChatInput + ChatContainer integration

**Files to create:**
- `src/components/beta/UserBubble.tsx` — Right-aligned user message bubble
- `src/components/beta/AssistantBubble.tsx` — Left-aligned assistant message bubble with Leasefy AI branding
- `src/components/beta/ChatInput.tsx` — Text input with send button, Enter/Shift+Enter
- `src/components/beta/ChatContainer.tsx` — Wires useBetaChat + bubbles + input + BetaWelcome empty state

**Files to modify:**
- `src/app/panel/beta/page.tsx` — Replace BetaWelcome with ChatContainer
- `src/app/panel/inmobiliaria/beta/page.tsx` — Same change

**UserBubble (`UserBubble.tsx`):**
- Right-aligned with `ml-auto max-w-[75%]`
- Avatar circle with user initials (hardcoded "NG" for mock, or first 2 chars of "Usuario")
- Background: `bg-indigo-500 text-white` (brand color)
- Rounded corners: `rounded-2xl rounded-br-sm` (chat bubble shape)
- Shows timestamp below in muted text
- Props: `message: ChatMessage`

**AssistantBubble (`AssistantBubble.tsx`):**
- Left-aligned with `mr-auto max-w-[75%]`
- Sparkle icon as avatar (indigo, consistent with BetaWelcome)
- Background: `bg-card` with border
- Rounded corners: `rounded-2xl rounded-bl-sm`
- Content: plain text (markdown rendering added in 18-02)
- Shows "Leasefy AI" label above bubble
- When status === 'streaming', show streaming content with blinking cursor
- Props: `message: ChatMessage, streamingContent?: string`

**ChatInput (`ChatInput.tsx`):**
- Auto-resizing `<textarea>` (1 row default, grows to max 5 rows)
- Send button with `PaperPlaneTilt` Phosphor icon (indigo)
- Enter sends, Shift+Enter adds newline
- Button disabled when empty or isStreaming
- Props: `onSend: (text: string) => void, disabled?: boolean`
- Sticky at bottom of chat area

**ChatContainer (`ChatContainer.tsx`):**
- Uses `useBetaChat()` hook
- If messages.length === 0: show `<BetaWelcome onPromptClick={sendMessage} />`
- If messages.length > 0: show message list + ChatInput at bottom
- Layout: flex-col h-full with messages area (flex-1 overflow-y-auto) and input (sticky bottom)
- Maps messages to UserBubble/AssistantBubble based on role
- Passes streamingContent to the last assistant bubble when isStreaming

**Page updates:**
- Both page.tsx files change from `<BetaWelcome />` to `<ChatContainer />`

**Must-haves for Task 2:**
1. User messages render right-aligned with indigo background
2. Assistant messages render left-aligned with card background and Sparkle icon
3. ChatInput sends on Enter, newline on Shift+Enter
4. ChatInput auto-resizes textarea
5. Send button disabled while streaming or empty input
6. Empty state shows BetaWelcome with functional onPromptClick
7. Both /panel/beta and /panel/inmobiliaria/beta render ChatContainer
8. Streaming message shows partial content with blinking cursor

**Commit:** `feat(18): message bubbles, ChatInput, and ChatContainer with mock chat`
