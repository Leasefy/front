# Plan 20-01: Agent Types, Execution State, and Activity Indicators

## Goal

Define agent type system, execution state model, and build the visual indicators showing when the orchestrator is dispatching agents. Users see animated badges for each agent being executed, with running/completed/failed status.

## Requirements Addressed

- **AGNT-01**: Visual indicator when AI orchestrator is dispatching agents
- **AGNT-02**: Agent name badges with icons (Cobranza, Pipeline, Documentos, etc.)
- **AGNT-03**: Agent execution status (running/completed/failed) shown inline
- **AGNT-05**: Multiple agents can show as executing simultaneously

## Tasks

### Task 1: Agent types + execution model + mock data

**Files:**
- MODIFY `src/lib/types/beta-chat.ts` — Add agent-related types
- CREATE `src/lib/data/mock-agent-executions.ts` — Mock agent execution scenarios

**Types to add to `beta-chat.ts`:**

```typescript
/** Agent types matching AI-AGENT-ARCHITECTURE.md */
export type AgentType =
  | 'cobranza'
  | 'pipeline'
  | 'mantenimiento'
  | 'documentos'
  | 'comunicacion'
  | 'reportes';

export type AgentExecutionStatus = 'dispatching' | 'running' | 'completed' | 'failed';

export interface AgentExecution {
  id: string;
  agentType: AgentType;
  /** Brief description of what the agent is doing */
  taskDescription: string;
  status: AgentExecutionStatus;
  startedAt: Date;
  completedAt?: Date;
  /** Duration in ms (for display) */
  durationMs?: number;
  /** Error message if status === 'failed' */
  error?: string;
}

/** An agent activity block in the conversation */
export interface AgentActivityBlock {
  id: string;
  /** Which message this activity belongs to (the assistant response) */
  messageId: string;
  agents: AgentExecution[];
  startedAt: Date;
}
```

**Extend ChatMessage:**
```typescript
export interface ChatMessage {
  // ... existing fields
  /** Agent executions associated with this assistant response */
  agentActivity?: AgentActivityBlock;
}
```

### Task 2: Agent activity indicator components

**Files:**
- CREATE `src/components/beta/AgentBadge.tsx` — Single agent badge with status
- CREATE `src/components/beta/AgentActivityIndicator.tsx` — Multi-agent activity block

**AgentBadge component:**
- Shows agent icon (Phosphor icon) + label
- Status-dependent styling:
  - `dispatching`: pulsing border, muted
  - `running`: spinning loader icon, active color
  - `completed`: checkmark, green accent
  - `failed`: X icon, red accent
- Compact pill-shape design, similar to existing badge patterns
- Transition animations between states

**AgentActivityIndicator component:**
- Wraps 1-N AgentBadge components
- Shows "Consultando agentes..." header text while any agent is running
- Badges appear with staggered animation (100ms delay between each)
- When all agents complete: header changes to "Agentes completados"
- Uses flexbox wrap for multiple badges
- Visually distinct from regular messages (subtle different background or border)

**Acceptance criteria:**
- AgentBadge renders correct icon/color per agent type
- All 4 statuses display correctly (dispatching/running/completed/failed)
- Multiple badges render horizontally with wrapping
- Staggered animation on badge appearance
- Responsive: badges wrap on narrow containers
