# Plan 23-01: Autonomy Settings Page with Per-Agent Toggles

## Goal

Create a preferences settings page accessible from the Beta sidebar where users configure how autonomous each AI agent type operates (auto, ask-first, manual).

## Requirements Addressed

- **PREF-01**: Settings page for AI autonomy levels per category (cobranza, mantenimiento, comunicacion)
- **PREF-02**: Autonomy toggles: auto/ask-first/manual for each agent type

## Tasks

### Task 1: Preferences types and default data

**Files:**
- MODIFY `src/lib/types/beta-chat.ts` — Add preference types
- CREATE `src/lib/data/default-preferences.ts` — Default settings and helpers

**Types to add (beta-chat.ts):**
```ts
/** Autonomy level for each agent type */
export type AutonomyLevel = 'auto' | 'ask_first' | 'manual';

/** User preferences for the AI Beta platform */
export interface BetaPreferences {
  /** Per-agent autonomy settings */
  autonomy: Record<AgentType, AutonomyLevel>;
  /** Notification preferences */
  notifications: NotificationPreferences;
  /** Communication tone */
  tone: CommunicationTone;
  /** Threshold settings */
  thresholds: ThresholdSettings;
}

export type CommunicationTone = 'formal' | 'professional' | 'casual';

export interface NotificationPreferences {
  /** Which categories to notify about */
  categories: Record<AgentType, boolean>;
  /** Notification channel preference */
  channel: 'in_app' | 'email' | 'whatsapp' | 'all';
}

export interface ThresholdSettings {
  /** Days of mora tolerance before escalation */
  moraTolerance: number;
  /** Max maintenance budget (COP) before requiring approval */
  maintenanceBudgetLimit: number;
  /** Min risk score to auto-approve candidates */
  minCandidateScore: number;
}
```

**default-preferences.ts:**
- Export `DEFAULT_PREFERENCES: BetaPreferences` with sensible defaults
  - All agents: `ask_first` (safest default)
  - All notification categories: enabled
  - Channel: `in_app`
  - Tone: `professional`
  - Mora tolerance: 5 days
  - Maintenance budget: 500000 (COP)
  - Min candidate score: 70

- Export `AUTONOMY_LEVELS` array for UI:
  ```ts
  { id: 'auto', label: 'Automatico', description: 'El agente actua sin consultar', icon: 'Lightning' }
  { id: 'ask_first', label: 'Preguntar primero', description: 'El agente consulta antes de actuar', icon: 'ChatCircle' }
  { id: 'manual', label: 'Manual', description: 'Deshabilitado — tu tomas las acciones', icon: 'Hand' }
  ```

**Acceptance criteria:**
- Types compile with zero errors
- Defaults are realistic for Colombian rental management
- All agent types from `AgentType` have corresponding autonomy settings

### Task 2: Preferences state in useBetaChat

**Files:**
- MODIFY `src/lib/hooks/useBetaChat.ts` — Add preferences state with localStorage persistence
- MODIFY `src/lib/context/BetaChatContext.tsx` — Expose preferences in context

**useBetaChat changes:**
- Add state: `preferences: BetaPreferences` (initialized from localStorage or defaults)
- Add function: `updatePreferences(partial: Partial<BetaPreferences>)` — merges partial update into preferences
- Add function: `resetPreferences()` — restores to DEFAULT_PREFERENCES
- Persist preferences to localStorage under key `leasefy-beta-preferences`
- Expose `preferences`, `updatePreferences`, `resetPreferences` in UseBetaChatReturn

**Acceptance criteria:**
- Preferences load from localStorage on init
- updatePreferences merges partial updates without replacing entire object
- resetPreferences restores all defaults
- Changes persist across page refresh

### Task 3: Settings sidebar tab and AutonomySettings page

**Files:**
- MODIFY `src/components/beta/BetaSidebar.tsx` — Add "Configuracion" tab
- CREATE `src/components/beta/PreferencesPanel.tsx` — Container with sub-sections
- CREATE `src/components/beta/AutonomySettings.tsx` — Per-agent autonomy toggles

**BetaSidebar changes:**
- Add new tab: `{ id: 'settings', label: 'Configuracion', icon: GearSix }`
- Update `BetaTab` type to include `'settings'`
- Render `<PreferencesPanel />` when `activeTab === 'settings'`

**PreferencesPanel component:**
- Full-height scrollable container
- Renders AutonomySettings (this plan) at top
- Placeholder slots for notification prefs, tone, thresholds (plan 23-02)
- Section dividers between groups

**AutonomySettings component:**
- Section header: "Autonomia de Agentes" with subtitle
- For each agent type (from AGENT_METADATA):
  - Agent label + colored icon badge
  - Three-option segmented control (radio-button group): Auto | Preguntar | Manual
  - Active option highlighted with indigo background
  - Brief description below the selected option
- Color-coded left border per agent (matching AGENT_METADATA color tokens)
- "Restablecer por defecto" link at bottom

**UI Pattern (matching inmobiliaria config style):**
- Cards with rounded borders, divided into sections
- Segmented controls styled as pill-shaped button groups
- Agent metadata colors for visual consistency with agent badges elsewhere
- Compact layout fitting in the main content area (not sidebar)

**Acceptance criteria:**
- Settings tab appears in sidebar after "Briefing"
- AutonomySettings shows all 6 agent types with correct labels/icons
- Clicking an autonomy level updates preferences state
- Selected level visually highlighted
- "Restablecer por defecto" resets all to ask_first
- Changes persist via localStorage
