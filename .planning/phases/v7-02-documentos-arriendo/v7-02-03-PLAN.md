<objective>
Harden the documentos page for Habeas Data (DOCU-04): (1) route application-document
download/view through the signed-URL hook (`useSignedDocUrl` → blob, hiding the Supabase
URL) instead of the raw `doc.url` in `href`/`iframe`/`img`; (2) gate document access behind
a per-purpose consent block (avalúo model — separate booleans, unchecked default, Ley 1581
notice); (3) surface a real ARCO delete wired to `documentsApi.delete` behind a type-to-confirm
Dialog, EXCLUDING the signed contrato firmado (a legal record with statutory retention).

Depends on v7-02-01 (the lease section already added to this page) and v7-02-02 (the
`useSignedDocUrl` hook + `DocumentConsent` types + `getSignedUrl`/`recordConsent` contracts).

Purpose: Satisfy DOCU-04 on the tenant surface — signed access, per-purpose consent, working
ARCO delete — with the honest raw-URL backend-gap disclosure carried from v7-02-02.
Output: `src/app/inquilino/documentos/page.tsx` hardened.

**Honesty guardrail:** where `/documents/:id/signed-url` is not yet live, the blob fetch may
fall back to the raw `doc.url` — but ONLY behind the deprecation/disclosure already written in
v7-02-02, and the plan must NOT claim "sin IDOR" is fully met by the frontend. Prefer the signed
path; disclose the fallback in a code comment.
</objective>
