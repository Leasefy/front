# Plan 18-02: Markdown Rendering + Streaming Text Renderer

## Goal
Add markdown support to assistant messages so the AI can respond with rich formatting (bold, lists, tables, code blocks). Handle partial/streaming content gracefully.

## Context

Plan 18-01 builds AssistantBubble which renders `message.content` as plain text. This plan adds a MarkdownRenderer component that replaces the plain text, and upgrades mock responses to include markdown formatting.

### Key Decisions
- **react-markdown**: Lightweight, well-maintained, no build config. No extra dep for syntax highlighting (code blocks get basic styling with Tailwind prose).
- **No Streamdown**: Overkill for mock phase. If we adopt Vercel AI SDK in Phase 24, we can swap to Streamdown then.
- **Streaming partial markdown**: react-markdown handles incomplete markdown gracefully (unclosed bold, partial lists render as-is). No special handling needed.
- **Tailwind prose**: Use `prose prose-sm dark:prose-invert` for base markdown styling, with custom overrides for chat context (smaller font, tighter spacing).

## Tasks

### Task 1: Install react-markdown + build MarkdownRenderer component

**Dependencies to install:**
- `react-markdown` (npm install)

**Files to create:**
- `src/components/beta/MarkdownRenderer.tsx` — Reusable markdown renderer for chat messages

**MarkdownRenderer (`MarkdownRenderer.tsx`):**
- Wraps `<ReactMarkdown>` with chat-appropriate prose styles
- Custom component overrides:
  - `p`: `<p className="mb-2 last:mb-0">` (tighter paragraph spacing)
  - `ul`/`ol`: Proper list styling with indentation
  - `code` (inline): `bg-muted px-1.5 py-0.5 rounded text-[13px] font-mono`
  - `pre > code` (block): `bg-muted p-3 rounded-lg text-[13px] font-mono overflow-x-auto block`
  - `table`: `border-collapse w-full text-[13px]` with cell borders
  - `a`: `text-indigo-500 hover:underline`
  - `strong`: `font-semibold` (works with dark mode)
- Props: `content: string, className?: string, isStreaming?: boolean`
- When isStreaming, append blinking cursor span after content
- Base className: `prose prose-sm dark:prose-invert max-w-none`

**Must-haves for Task 1:**
1. react-markdown installed as dependency
2. MarkdownRenderer renders bold, italic, lists, code blocks, tables, links
3. Inline code has distinct background styling
4. Code blocks have monospace font and proper padding
5. Dark mode compatible (prose-invert)
6. Streaming cursor shown when isStreaming=true

**Commit:** `feat(18): MarkdownRenderer component with react-markdown`
