<objective>
Wire the PQRS DATA LAYER into the existing v7-03 case hub (SOLI-02 + SOLI-03). This fills the exact seam
v7-03 left open — the `CaseType` union already declares `'pqrs'`/`'mantenimiento'` with zero rows — so
PQRS/maintenance requests become real cases the moment `pqrsApi.listMine()` returns entities, with NO rework
of the aggregator's shape and NO change to the agency side.

Three honest deliverables:
1. **Pure PQRS→case mappers (SOLI-02).** In `tenant-case.ts` add `pqrsStatusToTone` (total over the 6-member
   `PqrsEstado`, capped at `'attention'` for `en_cotizacion`, `assertNever` exhaustive) + `pqrsStatusToLabel`
   (factual es-CO labels) + an OPTIONAL `TenantCase.solicitud` metadata object + `pqrsToCase(s)` mapper. The
   mapper NORMALIZES estado/timestamps and PASSES THROUGH the raw SLA/cost fields (`createdAt`, `slaVenceAt?`,
   `costoResponsable?`, `cotizacionMonto?`, `cotizacionId?`, `cotizacionAprobadaAt?`) — it does NOT compute the
   SLA (that sanctioned estimate lives in the presentation layer, v7-06-03/04). Reuse `PqrsEstado`/
   `CostoResponsable` from `@/lib/api/pqrs.types` (never a parallel enum).
2. **Tolerant list hook (SOLI-03).** `use-tenant-pqrs.ts` mirrors `useMyPaymentRequests` exactly (useState list
   + isLoading + error + refetch, useEffect fetch), sourced from `pqrsApi.listMine()` → `[]` on unavailable.
3. **Fold into the aggregator (SOLI-03).** `use-tenant-cases.ts` composes `useTenantPqrs`, pushes
   `pqrsToCase(s)` rows in the `useMemo` where the comment says "Forward-ref types … emit no rows", and
   extends `refetch`'s `Promise.all` + the `error ??` chain. `[]` → zero rows → the hub's "Próximamente"
   sections stay (PITFALLS 5). Extend `use-tenant-cases.test.ts` for the 0-PQRS→real-rows path.

Depends on v7-06-01 (pqrs.types additive fields + pqrsApi). This is wave 2: waves 3 (list/create + detail)
build on these mappers + hook.

Purpose: SOLI-02/03 — reuse the shared entity vocabulary + fold PQRS into the unified caso hub, honestly.
Output: pure PQRS mappers + tolerant list hook + aggregator fold, unit-tested.

**Guardrails:** reuse `PqrsEstado`/`CostoResponsable` (no fork); no alarm tone (CaseTone capped at attention);
normalize-never-compute in the mapper (SLA estimate is presentation-layer); `[]` → zero rows (no fabricated
cases); own-cases-only (listMine is JWT-scoped); no internal ids/agency notes leak into TenantCase (CASO-02);
es-CO labels; zero new npm packages.
</objective>
