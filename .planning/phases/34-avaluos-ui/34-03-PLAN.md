<task type="auto">
  <name>Task 1: AvaluoContext — state, step navigation, validation, submit</name>
  <files>src/components/avaluo/AvaluoContext.tsx</files>
  <action>
    Create a client context mirroring ApplicationContext's structure but for AvaluoFormData
    (from `@/lib/types/avaluo`). It is intentionally simpler — no localStorage required.

    Provider `AvaluoProvider({ children, initialEmail })`:
    - State: `formData` (init `createEmptyAvaluoFormData(initialEmail)`), `currentStep` (1),
      `isSubmitting`, `submitError: string | null`.
    - `totalSteps = 4`.
    - `updateFormData(partial: Partial<AvaluoFormData>)` — shallow merge into formData.
    - `nextStep()` / `prevStep()` / `goToStep(n)` — clamp 1..4.
    - `isStepValid(step): boolean`:
      - step 1 (Inmueble): `!!address && !!city && !!propertyType && areaM2 > 0`.
      - step 2 (Contacto): valid email regex on `identity` AND `purposeAvaluo === true`.
        (purposeDataset/purposeContacto are OPTIONAL — do not require them.)
      - step 3 (Fotos): `true` (photos optional per backend contract).
      - step 4 (Confirmación): `true`.
    - `canProceed = isStepValid(currentStep)`.
    - `completedSteps` — derive array of step numbers where isStepValid(step) is true.
    - `submitAvaluo()` async:
      - set isSubmitting true, clear error.
      - call `submitIntake(formData)` from the service. On success `{ id }`, use
        `useRouter().push('/avaluo/estado/' + id)`.
      - On thrown Error, map message to a friendly Spanish string and set submitError:
        'rate_limit' → "Demasiadas solicitudes, intentá de nuevo en unos minutos.",
        'validation_error' → "Revisá los datos del formulario.",
        'service_unavailable' → "El servicio no está disponible, intentá más tarde.",
        default → "No pudimos enviar tu solicitud. Intentá de nuevo."
      - finally set isSubmitting false.
    - Export `useAvaluo()` hook that throws if used outside provider (mirror useApplication).

    Do NOT add any payment logic here — payment lives only on the estado page (locked).
  </action>
  <verify>npx tsc --noEmit passes; exports AvaluoProvider + useAvaluo; isStepValid step 2 returns false when purposeAvaluo is false even with a valid email.</verify>
  <done>Context compiles; step-2 validation requires purposeAvaluo; submitAvaluo calls submitIntake and routes to /avaluo/estado/[id]; no payment code present.</done>
</task>
