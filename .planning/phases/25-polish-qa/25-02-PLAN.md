### Task 3: Keyboard shortcuts

**Files:**
- CREATE `src/hooks/useBetaKeyboardShortcuts.ts`
- MODIFY `src/components/beta/BetaLayout.tsx`

**Implementation:**

1. **useBetaKeyboardShortcuts hook:**
   ```tsx
   export function useBetaKeyboardShortcuts({
     onNewConversation: () => void,
     onClose?: () => void,
   }) {
     useEffect(() => {
       const handler = (e: KeyboardEvent) => {
         // Cmd/Ctrl + K → new conversation
         if ((e.metaKey || e.ctrlKey) && e.key === 'k') {
           e.preventDefault();
           onNewConversation();
         }
         // Esc → close drawer/modal (if onClose provided)
         if (e.key === 'Escape' && onClose) {
           onClose();
         }
       };
       window.addEventListener('keydown', handler);
       return () => window.removeEventListener('keydown', handler);
     }, [onNewConversation, onClose]);
   }
   ```

2. **Wire into BetaLayout:**
   - `useBetaKeyboardShortcuts({ onNewConversation: createConversation, onClose: closeDrawer })`
   - Esc closes mobile drawer if open
   - Cmd+K creates new conversation from anywhere in Beta

**Acceptance criteria:**
- Cmd/Ctrl+K creates new conversation from any Beta view
- Esc closes mobile sidebar drawer when open
- Shortcuts don't fire when typing in textarea/input (except Esc)

### Task 4: Accessibility improvements

**Files:**
- MODIFY all Beta components as needed

**Changes:**

1. **ARIA landmarks:**
   - BetaLayout main area: `role="main"`, `aria-label="Chat principal"`
   - BetaSidebar: `role="navigation"`, `aria-label="Navegación Beta"`
   - ConversationList: `role="list"`, items `role="listitem"`
   - Tab buttons: `role="tab"`, `aria-selected={isActive}`
   - Tab content: `role="tabpanel"`

2. **Focus management:**
   - After creating new conversation, focus ChatInput textarea
   - After sending message, keep focus on ChatInput
   - Mobile drawer: trap focus inside when open, return focus on close
   - Decision cards: after selecting option, announce result to screen reader

3. **ARIA labels on interactive elements:**
   - Delete conversation button: `aria-label={t('beta.conversations.deleteConfirm')}`
   - Retry agent button: `aria-label={t('beta.agents.retry')}`
   - Expand/collapse toggles: `aria-expanded={isExpanded}`
   - Decision option buttons: `aria-label="Seleccionar: {option.label}"`

4. **Screen reader announcements:**
   - When AI starts typing: `aria-live="polite"` on TypingIndicator container
   - When agent status changes: `aria-live="polite"` on AgentActivityIndicator
   - New messages: `aria-live="polite"` region in ChatContainer

5. **Skip navigation:**
   - "Skip to chat" link for screen readers (sr-only, visible on focus)

**Acceptance criteria:**
- All interactive elements have aria-labels
- Tab navigation follows WAI-ARIA tab pattern
- Focus trapped in mobile drawer when open
- aria-live regions announce dynamic content changes
- Keyboard-only navigation possible through entire Beta UI
