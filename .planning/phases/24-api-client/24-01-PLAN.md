# Plan 24-01: API Client Module + TypeScript Types + Environment Switching

## Goal

Create a typed API client module that defines all AI platform endpoints, request/response types, and an environment flag system to switch between mock and real API backends. This is the foundation that Plan 24-02 (streaming + mock layer) and Plan 24-03 (documentation) build on.

## Requirements Addressed

- **APIC-01**: API client module with typed endpoints for chat, conversations, decisions, briefings
- **APIC-06**: Environment flag to switch between mock and real API

## Tasks

### Task 1: API request/response types

**Files:**
- CREATE `src/lib/api/types.ts`

**Type definitions:**
```typescript
// ============================================================================
// Chat / Messages
// ============================================================================

/** POST /api/v1/ai/message — Send message to orchestrator */
interface SendMessageRequest {
  message: string;
  conversationId?: string;  // null = new conversation
  attachments?: string[];   // URLs
}

/** Streaming response events (SSE) — defined here, implemented in 24-02 */
type ChatStreamEvent =
  | { type: 'message_start'; conversationId: string; messageId: string }
  | { type: 'content_delta'; delta: string }
  | { type: 'agent_dispatch'; agents: AgentDispatchEvent[] }
  | { type: 'agent_status'; agentId: string; status: AgentExecutionStatus; durationMs?: number; error?: string }
  | { type: 'decision'; decision: PendingDecision }
  | { type: 'message_complete'; usage?: { inputTokens: number; outputTokens: number } }
  | { type: 'error'; code: string; message: string };

interface AgentDispatchEvent {
  id: string;
  agentType: AgentType;
  taskDescription: string;
}

// ============================================================================
// Conversations
// ============================================================================

/** GET /api/v1/ai/conversations */
interface ConversationsListResponse {
  conversations: ApiConversation[];
  total: number;
}

interface ApiConversation {
  id: string;
  title: string;
  lastMessage: string;
  messageCount: number;
  createdAt: string;  // ISO
  updatedAt: string;  // ISO
}

/** GET /api/v1/ai/conversations/:id */
interface ConversationDetailResponse {
  id: string;
  title: string;
  messages: ApiMessage[];
  createdAt: string;
  updatedAt: string;
}

interface ApiMessage {
  id: string;
  role: 'user' | 'assistant';
  content: string;
  agentActivity?: { agents: AgentDispatchEvent[] };
  decision?: PendingDecision;
  createdAt: string;
}

/** POST /api/v1/ai/conversations — Create new */
interface CreateConversationResponse {
  id: string;
  title: string;
  createdAt: string;
}

// ============================================================================
// Decisions
// ============================================================================

/** GET /api/v1/ai/decisions */
interface DecisionsListResponse {
  decisions: ApiDecisionEntry[];
  pendingCount: number;
}

interface ApiDecisionEntry {
  id: string;
  title: string;
  description: string;
  category: AgentType;
  options: DecisionOption[];
  selectedOptionId?: string;
  selectedAt?: string;
  conversationId: string;
  createdAt: string;
}

/** POST /api/v1/ai/decisions/:id/select */
interface SelectDecisionRequest {
  optionId: string;
  additionalContext?: string;
}

interface SelectDecisionResponse {
  status: 'accepted' | 'executing';
  actionsTriggered: string[];
}

// ============================================================================
// Briefings
// ============================================================================

/** GET /api/v1/ai/briefings */
interface BriefingsListResponse {
  briefings: ApiBriefing[];
}

interface ApiBriefing {
  id: string;
  type: 'daily' | 'weekly' | 'alert';
  date: string;
  greeting: string;
  overallSummary: string;
  sections: BriefingSection[];
  isNew: boolean;
  createdAt: string;
}

/** GET /api/v1/ai/briefings/latest */
type LatestBriefingResponse = ApiBriefing;

// ============================================================================
// Preferences
// ============================================================================

/** GET /api/v1/ai/preferences */
type PreferencesResponse = BetaPreferences;

/** PUT /api/v1/ai/preferences */
type UpdatePreferencesRequest = Partial<BetaPreferences>;
type UpdatePreferencesResponse = BetaPreferences;
```

Re-use existing types from `beta-chat.ts` (AgentType, AgentExecutionStatus, PendingDecision, DecisionOption, BriefingSection, BetaPreferences) via imports.

**Acceptance criteria:**
- All request/response types exported
- Imports from existing beta-chat.ts types (no duplication)
- ChatStreamEvent union type covers all SSE event kinds

### Task 2: API client module

**Files:**
- CREATE `src/lib/api/client.ts`

**Client structure:**
```typescript
import { getApiConfig } from './config';

class LeasefyAIClient {
  private baseUrl: string;

  constructor() {
    this.baseUrl = getApiConfig().baseUrl;
  }

  // Chat
  sendMessage(req: SendMessageRequest): EventSource | AsyncIterable<ChatStreamEvent>
  // → Implemented as SSE in 24-02

  // Conversations
  listConversations(): Promise<ConversationsListResponse>
  getConversation(id: string): Promise<ConversationDetailResponse>
  createConversation(): Promise<CreateConversationResponse>
  deleteConversation(id: string): Promise<void>

  // Decisions
  listDecisions(): Promise<DecisionsListResponse>
  selectDecision(id: string, req: SelectDecisionRequest): Promise<SelectDecisionResponse>

  // Briefings
  listBriefings(): Promise<BriefingsListResponse>
  getLatestBriefing(): Promise<LatestBriefingResponse>

  // Preferences
  getPreferences(): Promise<PreferencesResponse>
  updatePreferences(req: UpdatePreferencesRequest): Promise<UpdatePreferencesResponse>
}

export const aiClient = new LeasefyAIClient();
```

Each method uses `fetch()` with proper headers (`Content-Type: application/json`, `Authorization: Bearer ${token}`). The `sendMessage` method signature is defined here but the SSE implementation is in Plan 24-02.

For now, each method throws `new Error('Not implemented — use mock API')` with a comment directing to the mock layer. Plan 24-02 fills in the mock implementations.

**Acceptance criteria:**
- Class-based client with all endpoint methods
- Proper TypeScript signatures using types from Task 1
- Token auth placeholder (reads from cookie/localStorage)
- `sendMessage` returns SSE-compatible type

### Task 3: Environment configuration

**Files:**
- CREATE `src/lib/api/config.ts`

**Config module:**
```typescript
export interface ApiConfig {
  baseUrl: string;
  useMockApi: boolean;
  mockDelayMs: number;  // Configurable delay for mock responses
}

export function getApiConfig(): ApiConfig {
  const useMock = process.env.NEXT_PUBLIC_USE_MOCK_API !== 'false';
  return {
    baseUrl: process.env.NEXT_PUBLIC_AI_API_URL || '/api/v1/ai',
    useMockApi: useMock,
    mockDelayMs: parseInt(process.env.NEXT_PUBLIC_MOCK_DELAY_MS || '800', 10),
  };
}

export function isMockMode(): boolean {
  return getApiConfig().useMockApi;
}
```

- Default to mock mode (`NEXT_PUBLIC_USE_MOCK_API` defaults to `true` when not set)
- `NEXT_PUBLIC_AI_API_URL` for real backend URL
- `NEXT_PUBLIC_MOCK_DELAY_MS` for adjustable mock response timing

**Update `.env.example`** (if it exists) or create `.env.local.example`:
```
# AI API Configuration
NEXT_PUBLIC_USE_MOCK_API=true
NEXT_PUBLIC_AI_API_URL=/api/v1/ai
NEXT_PUBLIC_MOCK_DELAY_MS=800
```

**Acceptance criteria:**
- Config reads from environment variables
- Defaults to mock mode
- `isMockMode()` helper exported for conditional logic
- Documented environment variables
