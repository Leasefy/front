# Plan 23-02: Notification Preferences, Tone Selector, and Threshold Settings

## Goal

Complete the preferences page with notification settings, communication tone selection, and configurable thresholds for mora tolerance, maintenance budgets, and candidate scores.

## Requirements Addressed

- **PREF-03**: Notification preferences: what AI notifies about and via which channel
- **PREF-04**: Communication tone preference (formal/casual/professional)
- **PREF-05**: Threshold settings (mora tolerance, maintenance budget limits)

## Tasks

### Task 1: NotificationSettings component

**Files:**
- CREATE `src/components/beta/NotificationSettings.tsx`
- MODIFY `src/components/beta/PreferencesPanel.tsx` — Integrate NotificationSettings

**NotificationSettings component:**
- Section header: "Notificaciones" with Bell icon
- **Category toggles** (one per agent type):
  - Agent label + colored dot
  - Toggle switch on/off
  - Maps to `preferences.notifications.categories[agentType]`
  - All enabled by default
- **Channel selector** (segmented control):
  - Options: "En la app" | "Email" | "WhatsApp" | "Todos"
  - Active option highlighted with indigo background
  - Maps to `preferences.notifications.channel`
- Compact card layout matching AutonomySettings style

**Acceptance criteria:**
- Toggle switches enable/disable notifications per agent category
- Channel selector updates preferences
- Visual consistency with AutonomySettings section above

### Task 2: ToneSelector component

**Files:**
- CREATE `src/components/beta/ToneSelector.tsx`
- MODIFY `src/components/beta/PreferencesPanel.tsx` — Integrate ToneSelector

**ToneSelector component:**
- Section header: "Tono de Comunicacion" with ChatText icon
- Three cards in a row (or stacked on narrow widths):
  - **Formal**: "Estimado propietario, le informamos que..." — briefcase icon
  - **Profesional**: "Hola, te comparto la actualización de..." — handshake icon
  - **Casual**: "¡Ey! Todo listo con los cobros de..." — smiley icon
- Each card shows:
  - Tone label
  - Example text snippet (italic, muted)
  - Selected card has indigo ring/border
- Clicking a card updates `preferences.tone`

**Acceptance criteria:**
- Three tone options displayed with example text
- Selected tone visually distinguished
- Clicking updates preferences state immediately
- Matches overall settings page design language

### Task 3: ThresholdSettings component

**Files:**
- CREATE `src/components/beta/ThresholdSettings.tsx`
- MODIFY `src/components/beta/PreferencesPanel.tsx` — Integrate ThresholdSettings

**ThresholdSettings component:**
- Section header: "Umbrales y Limites" with Sliders icon
- Three settings with labeled inputs:
  1. **Tolerancia de mora**: Number input (1-30 days), suffix "dias"
     - Description: "Dias antes de escalar automaticamente un cobro vencido"
     - Default: 5
  2. **Presupuesto de mantenimiento**: Currency input (COP), formatted with thousands separator
     - Description: "Monto maximo que el agente puede aprobar sin consultar"
     - Default: $500,000
     - Display format: `$500.000 COP`
  3. **Puntaje minimo de candidato**: Number input (0-100) or range slider
     - Description: "Puntaje minimo de riesgo para auto-aprobar un candidato"
     - Default: 70
     - Visual: show colored indicator (red <50, amber 50-69, green 70+)

**Input styling:**
- Number inputs with increment/decrement buttons
- Inline unit labels (dias, COP, puntos)
- Real-time validation (min/max enforcement)
- Compact card layout

**Acceptance criteria:**
- All three thresholds configurable with proper min/max bounds
- Values update preferences state on change
- Currency formatting for COP (thousands separators with dots)
- Score indicator color changes based on value
- Matches overall settings page design language
