    **1. Create `src/components/beta/BetaSidebar.tsx`** — Mission Control sidebar:

    Structure (top to bottom):
    - **AppSwitcher** at top (import from `./AppSwitcher.tsx`)
    - **Separator/divider**
    - **Tab navigation** with 4 tabs (vertical list, not horizontal tabs):
      - Conversaciones — icon: `ChatCircle` from Phosphor — this is the default/active tab
      - Agentes — icon: `Robot` or `Lightning` from Phosphor
      - Decisiones — icon: `Scales` or `ListChecks` from Phosphor
      - Briefing — icon: `Newspaper` or `Article` from Phosphor
    - **"Nueva conversacion"** button at bottom — icon: `Plus` — styled as primary action (subtle, not overwhelming)
    - **Beta badge** — small pill at bottom: "Beta" in indigo-500 with sparkle icon

    Visual design:
    - Width: 260px (slightly wider than dashboard sidebar to accommodate conversation list later)
    - Background: `bg-white dark:bg-card` matching existing sidebar
    - Border right: `border-r border-neutral-200 dark:border-border`
    - Tab items: Similar to nav items in PlanSidebar — icon + label, active state with bg highlight
    - Active tab: `bg-neutral-100 dark:bg-[#1f1f21]` with `text-foreground`
    - Inactive tab: `text-muted-foreground` with hover effect

    State:
    - `activeTab` state: `'conversations' | 'agents' | 'decisions' | 'briefing'`
    - Default: `'conversations'`
    - Tab changes are local state for now (no routing, content swaps in future phases)
    - Accept `onTabChange` callback prop for parent communication

    Props:
    ```typescript
    interface BetaSidebarProps {
      basePath: string; // '/panel' or '/panel/inmobiliaria'
      activeTab?: string;
      onTabChange?: (tab: string) => void;
      className?: string;
    }
    ```

    **2. Create `src/components/beta/BetaLayout.tsx`** — the Mission Control layout:

    Structure:
    - Full-height flex container (`h-screen` or `h-[calc(100vh)]`)
    - Left: `<BetaSidebar />` (fixed width 260px)
    - Right: Main content area (flex-1) — renders `{children}` (chat area in future)
    - No PlanHeader — Beta has its own minimal header or none (clean chat UI)

    The layout REPLACES the standard dashboard layout within /beta/ routes. It should NOT include PlanSidebar or PlanHeader from the classic dashboard.

    Props:
    ```typescript
    interface BetaLayoutProps {
      children: React.ReactNode;
      basePath: string; // '/panel' or '/panel/inmobiliaria'
    }
    ```

    **3. Create Next.js layout files**:

    `src/app/panel/beta/layout.tsx`:
    ```
    - Import BetaLayout
    - Render <BetaLayout basePath="/panel">{children}</BetaLayout>
    - This overrides the parent (landlord) layout's content area
    ```

    `src/app/panel/inmobiliaria/beta/layout.tsx`:
    ```
    - Import BetaLayout
    - Render <BetaLayout basePath="/panel/inmobiliaria">{children}</BetaLayout>
    - This overrides the parent (inmobiliaria) layout's content area
    ```

    **CRITICAL**: The Beta layout.tsx files render WITHIN the parent dashboard layout. In Next.js App Router, nested layouts compose — so /panel/beta/layout.tsx renders inside /panel/(landlord)/layout.tsx. This means the classic sidebar will still be visible unless we handle it.

    **Solution**: The Beta layout should render a full-screen overlay or use CSS to fill the entire content area, effectively hiding the parent dashboard's main content area. The parent sidebar will still show (which is fine — it has the "AI Beta" nav item highlighted). OR, better approach: make the Beta layout take the full viewport and position absolute/fixed to cover the dashboard content.

    **Simplest approach**: The Beta layout renders inside the dashboard's main content area (the part to the right of PlanSidebar). Since PlanSidebar shows the "AI Beta" item as active, the user sees the sidebar with Beta selected + the Beta Mission Control fills the content area. The Mission Control sidebar (BetaSidebar) renders INSIDE the content area as a nested sidebar. This creates: [PlanSidebar | BetaSidebar | Chat Area].

    **Better approach per user vision**: The user wants a "separate universe." Make the Beta layout use `fixed inset-0 z-50` to take over the entire viewport. The AppSwitcher in BetaSidebar lets users return to Dashboard. This fully replaces the view.

    **Go with the "separate universe" approach**: `fixed inset-0 z-50 bg-plan-page` covers everything. AppSwitcher navigates back to /panel (or /panel/inmobiliaria).
