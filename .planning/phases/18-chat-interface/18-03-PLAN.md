# Plan 18-03: Typing Indicator, Auto-Scroll, and Session Persistence

## Goal
Polish the chat experience: add a typing indicator while the AI "thinks", auto-scroll to keep the latest message visible, and persist conversation state across page navigation within the Beta section.

## Context

After 18-01 and 18-02, we have a working chat with message bubbles, markdown, and streaming simulation. This plan adds the UX polish that makes it feel like a real chat app.

### Key Decisions
- **Typing indicator**: Animated three-dot bouncing indicator shown during the delay before streaming starts (the 800-1500ms "thinking" period)
- **Auto-scroll**: `scrollIntoView({ behavior: 'smooth' })` on a sentinel element at the bottom of the message list. Triggered on new message and during streaming content updates.
- **Smart scroll**: Only auto-scroll if user is near the bottom (within 100px). If user scrolled up to read history, don't force scroll.
- **Session persistence**: Lift chat state to React Context (`BetaChatProvider`) so it survives navigation between /panel/beta sub-routes and tab switches. NOT localStorage — just in-memory for the session.
- **No cross-page persistence yet**: Closing the Beta section or refreshing loses messages. Phase 19 (Conversation Management) handles persistent storage.

## Tasks

### Task 1: TypingIndicator + auto-scroll behavior

**Files to create:**
- `src/components/beta/TypingIndicator.tsx` — Animated typing dots component

**Files to modify:**
- `src/components/beta/ChatContainer.tsx` — Add TypingIndicator display + auto-scroll logic
- `src/lib/hooks/useBetaChat.ts` — Add `isThinking` state (true during pre-stream delay, before streaming starts)

**TypingIndicator (`TypingIndicator.tsx`):**
- Three animated dots with staggered bounce animation
- Wrapped in an AssistantBubble-like container (left-aligned, Sparkle icon, "Leasefy AI" label)
- CSS animation: `@keyframes bounce` with `animation-delay` for stagger
- Use Tailwind arbitrary values or inline style for animation
- Compact size: dots are 6px circles with 4px gap
- Color: `bg-muted-foreground/50` for dots
- Props: `className?: string` (keep it simple)

**useBetaChat changes:**
- Add `isThinking: boolean` to return value
- `isThinking` is true during the initial delay (800-1500ms) before streaming begins
- Timeline: user sends → isThinking=true → delay → isThinking=false, isStreaming=true → character reveal → isStreaming=false

**ChatContainer auto-scroll:**
- Add a `<div ref={scrollRef} />` sentinel at the bottom of messages list
- `useEffect` watching `messages.length`, `streamingContent`, `isThinking`:
  - Check if user is near bottom: `container.scrollHeight - container.scrollTop - container.clientHeight < 100`
  - If near bottom, call `scrollRef.current?.scrollIntoView({ behavior: 'smooth' })`
- Show TypingIndicator after last message when `isThinking` is true
- Show streaming AssistantBubble when `isStreaming` is true (already exists from 18-01)

**Must-haves for Task 1:**
1. Three animated bouncing dots appear while AI is "thinking"
2. Typing indicator positioned left-aligned like assistant messages
3. Auto-scroll triggers on new messages
4. Auto-scroll triggers during streaming content updates
5. Auto-scroll does NOT trigger if user scrolled up (>100px from bottom)
6. isThinking and isStreaming are distinct states in useBetaChat

**Commit:** `feat(18): typing indicator and smart auto-scroll`

### Task 2: BetaChatProvider context for session persistence

**Files to create:**
- `src/lib/context/BetaChatContext.tsx` — React Context wrapping useBetaChat state

**Files to modify:**
- `src/components/beta/BetaLayout.tsx` — Wrap children with BetaChatProvider
- `src/components/beta/ChatContainer.tsx` — Use context instead of direct useBetaChat
- `src/lib/hooks/useBetaChat.ts` — Extract state management to be context-compatible

**BetaChatContext (`BetaChatContext.tsx`):**
- `BetaChatProvider` component that wraps children
- Holds the chat state (messages, streaming state, conversation history)
- `useBetaChatContext()` hook for consuming components
- Standard React Context pattern (same as DecisionContext.tsx in the codebase)
- Throws error if used outside provider

**Architecture:**
```
BetaLayout (fixed inset-0)
  └─ BetaChatProvider   ← NEW: holds all chat state
       ├─ BetaSidebar
       └─ <main>
            └─ ChatContainer (consumes context)
```

**BetaLayout changes:**
- Import BetaChatProvider
- Wrap `{children}` and `<BetaSidebar>` inside `<BetaChatProvider>`
- This ensures chat state persists when switching BetaSidebar tabs (tab content will be added in future phases)

**ChatContainer changes:**
- Replace `useBetaChat()` with `useBetaChatContext()`
- No other logic changes — just the state source changes

**useBetaChat changes:**
- Keep as a standalone hook that manages state internally
- BetaChatProvider uses useBetaChat internally and exposes via context
- This way the hook can still be used standalone for testing

**Must-haves for Task 2:**
1. BetaChatProvider wraps all Beta content in BetaLayout
2. useBetaChatContext() returns same interface as useBetaChat
3. Chat messages survive switching BetaSidebar tabs
4. Chat messages survive navigating within /panel/beta/* routes
5. Error thrown if useBetaChatContext() used outside provider
6. Build succeeds with zero errors

**Commit:** `feat(18): BetaChatProvider for session-level persistence`
