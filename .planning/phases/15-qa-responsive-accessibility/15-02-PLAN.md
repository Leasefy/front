<tasks>

<task type="auto">
  <name>Task 1: Audit and fix image alt text and form labels</name>
  <files>All components and pages using img tags or forms</files>
  <action>
    1. Search for all img tags and Next.js Image components across the codebase
    2. For each, verify alt attribute exists and is descriptive (not empty string unless decorative)
    3. For decorative images: ensure alt="" and role="presentation"
    4. Search for all form inputs (input, select, textarea)
    5. For each, verify associated label exists via:
       - Wrapping <label> element
       - htmlFor/id pairing
       - aria-label or aria-labelledby attribute
    6. Fix any missing alt text or labels

    Common patterns to check:
    - Property images in cards and detail pages
    - User avatars
    - Icon images (should have aria-hidden if decorative)
    - Auth form inputs
    - Filter inputs on propiedades page
    - Wizard form fields
    - Settings form fields
  </action>
  <verify>grep -rn "&lt;img" src/ | grep -v "alt=" to find missing alt attributes</verify>
  <done>Zero img tags without alt, zero form inputs without labels</done>
</task>

<task type="auto">
  <name>Task 2: Audit and fix focus indicators and keyboard navigation</name>
  <files>src/app/globals.css, interactive components</files>
  <action>
    1. Verify focus-visible styles in globals.css apply to all interactive elements
    2. Search for any custom focus overrides that might hide focus indicators (focus:outline-none without focus-visible replacement)
    3. Check all clickable divs/spans have:
       - tabIndex={0} or role="button"
       - onKeyDown handler for Enter/Space
       - OR are wrapped in proper button/link elements
    4. Verify tab order is logical on key pages:
       - Home page: nav → hero → content → footer
       - Property detail: nav → images → info → CTA → footer
       - Dashboard: nav → sidebar → content
    5. Check modal/dialog focus trapping (focus stays inside when open)
    6. Verify Escape key closes modals/sheets

    Fix any interactive elements missing keyboard support.
  </action>
  <verify>grep -rn "focus:outline-none" src/ to find hidden focus indicators</verify>
  <done>All interactive elements have visible focus indicators and keyboard support</done>
</task>

</tasks>
