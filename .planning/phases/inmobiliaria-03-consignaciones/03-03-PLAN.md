# Plan 03-03: Detalle Consignación + Timeline + ActaEntrega

## Objective
Create the consignment detail page showing complete property information, consignment history timeline, inventory (acta de entrega), and current lease status if rented.

## Execution Context
- **Module**: Inmobiliaria Dashboard
- **Route**: `/panel/inmobiliaria/portafolio/[id]`
- **Patterns**: Detail page with sections, similar to property detail pages
- **Data**: Consignacion, InventoryItem types, getConsignacionById helper
- **Related**: Link to propietario and agente detail pages

## Context References
- `src/lib/types/inmobiliaria.ts:110-158` - Consignacion and InventoryItem types
- `src/lib/data/mock-inmobiliaria.ts:1912-1921` - getConsignacionById, helpers
- `src/components/inmobiliaria/PropietarioCard.tsx` - Card patterns
- `docs/ROADMAP-INMOBILIARIA.md:253-259` - Detalle requirements
