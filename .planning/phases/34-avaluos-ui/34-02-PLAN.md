<task type="auto">
  <name>Task 1: Wompi session route — server-side integrity hash</name>
  <files>src/app/api/avaluo/wompi-session/route.ts</files>
  <action>
    Create a Next.js App Router route handler. Use `export const runtime = 'nodejs'`
    (we need node:crypto; do NOT use the edge runtime).

    Export `async function POST(req: Request)`:
    - Parse JSON body: `{ submissionId: string }`. If missing, return
      `NextResponse.json({ error: 'submissionId required' }, { status: 400 })`.
    - Read secrets from server env (NO NEXT_PUBLIC prefix):
      `const integritySecret = process.env.WOMPI_INTEGRITY_SECRET`
      `const publicKey = process.env.WOMPI_PUBLIC_KEY`.
      If either is missing, return 500 with `{ error: 'wompi_not_configured' }`.
    - Build the payment params:
      - `const amountInCents = 5_000_000;` // $50.000 COP — certificate price, fixed for v1.
        Add a comment noting the price and that it is COP cents (Wompi expects cents).
      - `const currency = 'COP';`
      - `const reference = 'avaluo-' + submissionId;` (deterministic, ties the Wompi tx to
        the submission so the return handler can reconcile).
    - Compute the integrity hash EXACTLY per Wompi's spec — SHA-256 of the concatenation
      `reference + amountInCents + currency + integritySecret` (in that order, no separators):
      ```ts
      import { createHash } from 'node:crypto';
      const integrity = createHash('sha256')
        .update(`${reference}${amountInCents}${currency}${integritySecret}`)
        .digest('hex');
      ```
    - Return `NextResponse.json({ reference, amountInCents, currency, integrity, publicKey })`.
      Note: `publicKey` IS safe to return (it is the public key); the integrity SECRET is
      never returned and never leaves the server.

    Add a top-of-file comment block warning: "WOMPI_INTEGRITY_SECRET must NEVER be prefixed
    NEXT_PUBLIC_ — computing the hash client-side leaks the secret. This route is the single
    server-side source of the integrity hash."
  </action>
  <verify>
    npx tsc --noEmit passes. Manual: with WOMPI_INTEGRITY_SECRET + WOMPI_PUBLIC_KEY set in
    .env.local, `curl -X POST localhost:3000/api/avaluo/wompi-session -H 'content-type: application/json' -d '{"submissionId":"abc"}'`
    returns 200 JSON with reference "avaluo-abc", amountInCents 5000000, a 64-char hex integrity,
    and the publicKey. Without env vars set → 500 wompi_not_configured. rg confirms no NEXT_PUBLIC on the secret.
  </verify>
  <done>
    POST returns { reference, amountInCents, currency, integrity, publicKey }; integrity is a
    64-char SHA-256 hex; the integrity secret is read server-side only and never returned.
  </done>
