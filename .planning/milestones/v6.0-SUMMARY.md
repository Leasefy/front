## Limitación de verificación honesta
El **E2E real no es testeable en dev local**: `.env` apunta `NEXT_PUBLIC_BACKEND_URL` a prod y las credenciales demo de inmobiliaria son rechazadas por prod (no se puede iniciar sesión como agencia local). Los endpoints IA requieren el servicio `agent` corriendo + `OPENAI`/`ANTHROPIC` keys + JWT válido. Verificación hecha vía tsc + tests + rutas-200 + revisión de código; falta un smoke E2E manual con servicios reales.
