# Plan 22-01: Briefing Card with Sections, Mock Data, and Sidebar Integration

## Goal

Build the daily briefing card with expandable/collapsible sections (cobros, pipeline, mantenimiento, decisiones pendientes), mock briefing data with realistic Colombian rental scenarios, and integrate it into the BetaSidebar's "Briefing" tab.

## Requirements Addressed

- **BRFG-01**: Daily briefing card displayed at top of Beta section
- **BRFG-02**: Briefing sections: cobros summary, pipeline updates, mantenimiento, decisiones pendientes
- **BRFG-03**: Each briefing section expandable/collapsible

## Tasks

### Task 1: Briefing types

**Files:**
- MODIFY `src/lib/types/beta-chat.ts` — Add briefing types

**Types to add:**
- `BriefingSection`: `{ id: string; title: string; icon: string; color: string; summary: string; details: string[]; actionLabel?: string; actionContext?: string }`
- `DailyBriefing`: `{ id: string; date: Date; greeting: string; overallSummary: string; sections: BriefingSection[]; isNew: boolean }`

**Acceptance criteria:**
- Types exported and importable
- Sections match the 4 required categories (cobros, pipeline, mantenimiento, decisiones)

### Task 2: Mock briefing data

**Files:**
- CREATE `src/lib/data/mock-briefings.ts` — Mock briefing data generator

**Data structure:**
- `getTodayBriefing()` returns a `DailyBriefing` for "today" with:
  - **Cobros section**: "3 de 12 cobros recibidos este mes. $4.2M pendiente. 2 inquilinos en mora >15 dias."
  - **Pipeline section**: "5 aplicaciones nuevas. 2 candidatos con score >80. 1 propiedad sin aplicantes por 7 dias."
  - **Mantenimiento section**: "1 solicitud urgente (fuga Apt 502). 2 reparaciones programadas. Presupuesto mensual: 68% utilizado."
  - **Decisiones section**: "3 decisiones pendientes: renovacion contrato, aprobacion candidato, autorizacion reparacion."
- `getMockBriefings()` returns array of 5 briefings for the past 5 days (for history in 22-02)
- Each section has an `actionLabel` like "Cuéntame mas" and `actionContext` for chat integration
- Realistic COP amounts, Colombian apartment references, realistic names

**Acceptance criteria:**
- At least 5 mock briefings with varied data
- Each briefing has all 4 sections
- Data feels realistic for a Colombian rental portfolio

### Task 3: BriefingCard component

**Files:**
- CREATE `src/components/beta/BriefingCard.tsx` — Briefing card with collapsible sections

**Component design:**
- Props: `briefing: DailyBriefing; onAction?: (sectionId: string, context: string) => void`
- Top section: Date formatted ("Martes 10 de Febrero"), greeting, overall summary
- Sections rendered as collapsible panels using grid-rows-[0fr]/[1fr] transition (same pattern as AgentResultCard)
- Each section shows:
  - Icon (from section metadata) + title + chevron toggle
  - Summary text always visible
  - Expanded: detail bullet points + action button ("Cuéntame mas sobre cobros")
- Default: first section expanded, rest collapsed
- Section header has left colored border matching agent metadata colors
- "Nuevo" badge if `briefing.isNew === true`

**Acceptance criteria:**
- All 4 sections render with correct icons and colors
- Collapse/expand animation works smoothly
- Action button present in expanded sections
- Visual consistency with existing Beta UI (indigo accents, rounded corners, neutral borders)

### Task 4: Sidebar briefing tab + useBetaChat extension

**Files:**
- MODIFY `src/lib/hooks/useBetaChat.ts` — Add briefing state management
- MODIFY `src/components/beta/BetaSidebar.tsx` — Replace "Fase 22" placeholder with BriefingCard

**useBetaChat changes:**
- Import `getTodayBriefing` from mock-briefings
- Add state: `currentBriefing: DailyBriefing | null` (initialized from `getTodayBriefing()`)
- Add function: `sendBriefingAction(sectionId: string, context: string)` — switches to conversations tab and sends a message like "Cuéntame mas sobre mis cobros"
- Expose `currentBriefing` and `sendBriefingAction` in `UseBetaChatReturn`

**BetaSidebar changes:**
- Replace "Fase 22" placeholder with `<BriefingCard />` when `activeTab === 'briefing'`
- Wire `onAction` to `sendBriefingAction` (which should also switch to conversations tab)

**Acceptance criteria:**
- Briefing tab shows today's briefing card
- Clicking section actions navigates to conversations tab and sends the contextual message
- Existing tabs unchanged
- BriefingCard scrollable in the sidebar's overflow container

## Integration Points

- BriefingCard `onAction` → triggers `sendBriefingAction` → sends message and switches to conversations tab
- Counter badge pattern (from Phase 21) reused for BRFG-05 in plan 22-02
- Mock data structure matches future API contract (Phase 24)
