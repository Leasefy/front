# Plan 25-01: Dark Mode Audit + Responsive Mobile Chat

## Goal

Ensure dark mode works flawlessly across all Beta UI and create a mobile-first responsive chat experience where the sidebar becomes a slide-out drawer and chat is full-screen.

## Requirements Addressed

- **PLSH-01**: Dark mode compatible across all Beta UI
- **PLSH-02**: Responsive design: mobile chat experience (full-screen chat)

## Tasks

### Task 1: Dark mode audit and fixes

**Files:**
- AUDIT all 23 `src/components/beta/*.tsx` files

**What to check:**
Most components already use `dark:` Tailwind variants. Audit for:
1. Any hardcoded light colors without `dark:` counterpart (e.g., `bg-white` missing `dark:bg-card`)
2. Border colors: `border-neutral-200` should have `dark:border-border`
3. Text colors: `text-neutral-*` should have `dark:text-*` fallback
4. Hover states: `hover:bg-neutral-50` should have `dark:hover:bg-*`
5. Agent metadata colors (inline styles or dynamic classes) work in dark mode
6. Decision card option highlights (emerald/red rings) visible in dark mode

**Strategy:** Read each component, grep for patterns missing `dark:` variants, fix any gaps.

**Acceptance criteria:**
- Zero hardcoded light-only colors in Beta components
- All borders, backgrounds, text, and hover states have dark mode variants
- Agent status badges (green/red/amber) readable in both themes

### Task 2: Mobile layout - hamburger menu + sidebar drawer

**Files:**
- MODIFY `src/components/beta/BetaLayout.tsx`
- CREATE `src/components/beta/MobileSidebarDrawer.tsx`

**Current state:**
```tsx
// BetaLayout.tsx line 43
<div className="hidden md:flex">
  <BetaSidebar ... />
</div>
```

The sidebar is completely hidden on mobile (`hidden md:flex`), with no way to access conversations, decisions, or briefings.

**Implementation:**

1. **MobileSidebarDrawer component:**
   - Backdrop overlay (bg-black/50) when open
   - Slide-in panel from left (w-[280px])
   - Contains `BetaSidebar` with same props
   - Close on backdrop click or swipe left
   - CSS transition for smooth slide animation (translate-x)
   - Portal or fixed positioning at z-60

2. **Mobile header bar in BetaLayout:**
   - Only visible on mobile (`md:hidden`)
   - Hamburger button (List icon) to toggle drawer
   - "Leasefy AI" title centered
   - "New chat" button (Plus icon) on the right
   - Height: 48px, sticky top

3. **Updated BetaLayout structure:**
   ```tsx
   <div className="fixed inset-0 z-50 flex flex-col md:flex-row bg-plan-page">
     {/* Mobile header - visible only on mobile */}
     <div className="md:hidden flex items-center ...">
       <button onClick={toggleDrawer}><List /></button>
       <span>Leasefy AI</span>
       <button onClick={createConversation}><Plus /></button>
     </div>

     {/* Desktop sidebar - hidden on mobile */}
     <div className="hidden md:flex">
       <BetaSidebar ... />
     </div>

     {/* Mobile drawer - shown when toggled */}
     <MobileSidebarDrawer open={drawerOpen} onClose={closeDrawer}>
       <BetaSidebar ... />
     </MobileSidebarDrawer>

     {/* Main content - fills remaining space */}
     <main className="flex-1 overflow-y-auto">
       {activeTab === 'settings' ? <PreferencesPanel /> : children}
     </main>
   </div>
   ```

**Acceptance criteria:**
- Mobile (< 768px): Chat is full-screen, mobile header visible with hamburger
- Mobile: Hamburger opens sidebar as drawer overlay from left
- Mobile: Drawer closes on backdrop click
- Desktop (>= 768px): No change — sidebar inline as before
- Mobile header shows "Leasefy AI" title + new chat button
