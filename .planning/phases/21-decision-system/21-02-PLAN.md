# Plan 21-02: Decision Counter Badge, Sidebar Decisions Tab, and History

## Goal

Add a pending decisions counter badge to the BetaSidebar "Decisiones" tab, and implement the decisions tab content showing decision history (pending and resolved decisions accessible from the sidebar).

## Requirements Addressed

- **DCSN-05**: Pending decisions counter in Beta sidebar nav item
- **DCSN-06**: Decision history accessible (what was decided and when)

## Tasks

### Task 1: Pending decisions counter and useBetaChat extension

**Files:**
- MODIFY `src/lib/hooks/useBetaChat.ts` — Expose `pendingDecisionsCount` computed value
- MODIFY `src/components/beta/BetaSidebar.tsx` — Add counter badge to Decisiones tab

**useBetaChat changes:**
- Add computed `pendingDecisionsCount`: count messages across all conversations where `message.decision` exists and `!message.decision.selectedOptionId`
- Add computed `allDecisions`: flat array of `{ decision: PendingDecision; conversationId: string; conversationTitle: string; messageId: string }` from all conversations
- Expose both in `UseBetaChatReturn`

**BetaSidebar changes:**
- For the "Decisiones" tab item: show a small count badge when `pendingDecisionsCount > 0`
- Badge style: small indigo circle with white number (similar to notification badges)
- Badge positioned to the right of the tab label
- Animates in/out when count changes (simple opacity/scale transition)

**Acceptance criteria:**
- Badge shows correct count of unresolved decisions
- Badge updates when a decision is made (count decreases)
- Badge hidden when count is 0
- Existing sidebar styling and tabs unchanged

### Task 2: Decisions tab content (history view)

**Files:**
- CREATE `src/components/beta/DecisionHistory.tsx` — Decision history panel
- MODIFY `src/components/beta/BetaSidebar.tsx` — Render DecisionHistory in decisions tab

**DecisionHistory component:**
- Consumes `allDecisions` from useBetaChatContext
- Grouped into two sections:
  - "Pendientes" — decisions without `selectedOptionId` (yellow/amber accent)
  - "Resueltas" — decisions with `selectedOptionId` (green accent)
- Each decision entry shows:
  - Decision title
  - Category badge (from AGENT_METADATA)
  - For resolved: selected option label + timestamp
  - For pending: number of options available
- Clicking a decision entry switches to that conversation (via `switchConversation`)
- Empty state: "No hay decisiones aun" centered text

**BetaSidebar changes:**
- Replace the "Fase 21" placeholder with `<DecisionHistory />` for the decisions tab

**Acceptance criteria:**
- Decisions tab shows all decisions across conversations
- Pending and resolved sections render correctly
- Clicking a decision navigates to its conversation
- Empty state shows when no decisions exist
- Existing tabs (conversations, agents, briefing) unchanged

## Integration Points

- Counter badge pattern reusable for briefing notifications (Phase 22, BRFG-05)
- Decision history data structure informs API client types (Phase 24)
- allDecisions computed from conversation state — no additional storage needed
