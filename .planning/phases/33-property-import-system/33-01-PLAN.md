  <name>Task 3: Create column mapping engine</name>
  <files>src/components/inmobiliaria/import/lib/columnMapping.ts</files>
  <action>
    Implement the two-tier column matching heuristic:

    **Tier 1: Keyword Dictionary (confidence 0.9+)**
    ```typescript
    export const COLUMN_KEYWORDS: Record<string, string[]> = {
      propertyTitle:    ['titulo', 'nombre', 'inmueble', 'propiedad', 'descripcion corta'],
      propertyAddress:  ['direccion', 'dirección', 'address', 'ubicacion', 'ubicación', 'calle'],
      propertyCity:     ['ciudad', 'municipio', 'city'],
      propertyZone:     ['barrio', 'zona', 'sector', 'localidad', 'urbanizacion', 'urbanización'],
      propertyType:     ['tipo', 'tipo inmueble', 'clase', 'type'],
      monthlyRent:      ['canon', 'arriendo', 'valor', 'precio', 'alquiler', 'renta', 'mensual', 'rent'],
      adminFee:         ['admin', 'administracion', 'administración', 'cuota admin', 'copropiedad'],
      commissionPercent:['comision', 'comisión', 'fee', 'honorario', 'honorarios'],
    };
    ```

    **Normalization function:**
    - Lowercase
    - Strip accents (`normalize('NFD').replace(/[\u0300-\u036f]/g, '')`)
    - Trim whitespace

    **Tier 2: Levenshtein Distance (confidence 0.5-0.89)**
    Implement inline Levenshtein (standard dynamic programming, ~20 lines). For unmatched headers, compute distance against all keyword entries. Accept if `(1 - distance/maxLen) >= 0.5`.

    **`autoMapColumns(headers: string[]): ColumnMapping[]`**
    - For each header, try Tier 1 first (exact substring match against keywords).
    - If no Tier 1 match, try Tier 2 with Levenshtein.
    - If no match at all, set `targetField: null`, `confidence: 0`.
    - Ensure no two headers map to the same targetField (if duplicate, keep the one with higher confidence, set the other to null).
    - Return array of ColumnMapping objects.
  </action>
</task>
