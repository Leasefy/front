  <action>
    Create reusable chart components using pure CSS/Tailwind (no external charting library).

    TrendChart (line-style):
    - Props: { data: { label: string; value: number }[]; maxValue?: number; height?: number; color?: string }
    - Renders a series of dots connected by CSS — each dot positioned proportionally
    - Labels on x-axis, values shown on hover or inline
    - Simple but clean — think sparkline at larger scale
    - Default height: 120px, color: neutral-500

    BarChart (bar-style):
    - Props: { data: { label: string; value: number; secondaryValue?: number }[]; maxValue?: number; height?: number; color?: string; secondaryColor?: string }
    - Renders vertical or horizontal bars proportionally
    - If secondaryValue provided: shows stacked or side-by-side bars (for expected vs collected)
    - Labels below bars
    - Default height: 160px

    Both components should be 'use client', use cn() for classes, be responsive.
    Keep it simple — no SVG, no canvas, just div widths/heights with transitions.
  </action>
  <verify>npx next build --no-lint | grep "Compiled"</verify>
  <done>TrendChart and BarChart exported, render pure CSS charts</done>
