# Plan 03-02: ConsignacionWizard (6-Step New Consignment)

## Objective
Create a comprehensive 6-step wizard for registering new property consignments. This is the core workflow for onboarding properties from owners to the agency's portfolio.

## Execution Context
- **Module**: Inmobiliaria Dashboard
- **Route**: `/panel/inmobiliaria/portafolio/nuevo`
- **Patterns**: Multi-step wizard with progress indicator
- **Data**: ConsignacionFormData, PropietarioFormData types
- **Mock Integration**: Add new consignacion to client state (no persistence)

## Context References
- `src/lib/types/inmobiliaria.ts:160-172` - ConsignacionFormData type
- `src/lib/types/inmobiliaria.ts:42-55` - PropietarioFormData type
- `src/components/inmobiliaria/PropietarioCard.tsx` - Compact variant for selection
- `src/components/inmobiliaria/PropietarioForm.tsx` - Inline propietario creation
- `src/lib/data/mock-inmobiliaria.ts` - MOCK_PROPIETARIOS, MOCK_AGENTES
- `docs/ROADMAP-INMOBILIARIA.md:244-250` - Wizard steps specification

## Tasks

<task id="1" type="component" priority="high">
<title>Create PropietarioSelector component</title>
<description>
Build a reusable selector for choosing an existing propietario or creating a new one inline.

Features:
- Search input to filter existing propietarios
- Grid of PropietarioCard (compact variant) for selection
- Selected state with checkmark
- "Agregar nuevo propietario" button that expands inline form
- Inline PropietarioForm (collapsible)
- Validation: must select or create one propietario

Props:
- value: string | null (propietarioId)
- onChange: (id: string, data?: PropietarioFormData) => void
- newPropietarioData?: PropietarioFormData (for inline creation)
</description>
<acceptance>
- Search filters propietarios by name
- Selection highlights card with visual feedback
- Inline form validates all required fields
- Returns propietarioId on selection
</acceptance>
</task>

<task id="2" type="component" priority="high">
<title>Create AgenteSelector component</title>
<description>
Build a selector for assigning an agent to the consignment.

Display each agent as a card showing:
- Avatar (or initials)
- Name and role
- Zone/specialization
- Current property load (assignedPropertyIds.length)
- Commission split percentage

Features:
- Grid of agent cards
- Single selection with visual highlight
- Filter by zone (optional)
- Sort by workload (lowest first as recommended)
</description>
<acceptance>
- All active agents from MOCK_AGENTES displayed
- Selection state clear and obvious
- Workload visible to help assignment decisions
</acceptance>
</task>

<task id="3" type="component" priority="high">
<title>Create ConsignacionWizardSteps components</title>
<description>
Build individual step components for the wizard.

Step 1 - SelectPropietario:
- Uses PropietarioSelector
- Title: "Seleccionar Propietario"
- Subtitle: "Elige un propietario existente o crea uno nuevo"

Step 2 - PropertyData:
- Form fields: propertyTitle, propertyAddress, propertyCity, propertyZone
- propertyType dropdown (apartment, house, studio, commercial, office, warehouse)
- monthlyRent (currency input)
- adminFee (optional currency input)
- Validation: all required fields

Step 3 - CommissionTerms:
- commissionPercent slider (8-15%, default 10%)
- minimumTerm dropdown (6, 12, 18, 24 months)
- Contract start date picker
- Terms summary showing agency vs owner split

Step 4 - AssignAgent:
- Uses AgenteSelector
- Title: "Asignar Agente"
- Shows recommended agents (lowest workload)

Step 5 - ActaEntrega:
- Inventory items list (add/remove)
- Each item: name, quantity, condition dropdown
- Photo upload placeholder (UI only, no actual upload)
- Notes textarea

Step 6 - Confirmation:
- Summary of all entered data
- Propietario info
- Property details
- Terms summary
- Assigned agent
- Inventory count
- Edit buttons to go back to specific steps
- "Confirmar Consignación" button
</description>
<acceptance>
- Each step validates before allowing next
- Data persists across step navigation
- Back button returns to previous step with data intact
- Summary shows all collected data
</acceptance>
</task>

<task id="4" type="component" priority="high">
<title>Create ConsignacionWizard orchestrator</title>
<description>
Build the main wizard component that orchestrates all steps.

Features:
- Step indicator with numbered circles (1-6)
- Current step highlighted
- Completed steps with checkmark
- Step labels below indicators
- Content area for current step component
- Footer with Back/Next buttons
- Cancel button with confirmation dialog
- Progress bar (alternative to step circles)

State management:
- currentStep: number (1-6)
- formData: Partial<ConsignacionFormData & extras>
- isValid: boolean per step
- isSubmitting: boolean

On submit:
- Log to console (mock - no API)
- Show success toast
- Redirect to /panel/inmobiliaria/portafolio
</description>
<acceptance>
- Step navigation works correctly
- Cannot proceed without valid step data
- Can go back and edit previous steps
- Final submit shows success feedback
- Cancel prompts confirmation
</acceptance>
</task>
